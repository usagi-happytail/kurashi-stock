# くらしストック — 家庭用品在庫管理アプリ

食品・洗剤・紙製品・防災備蓄などを一元管理する、日本語のブラウザアプリです。**アカウント不要・在庫データの外部送信なし・ビルド不要**で動作します。

## 機能（v1.0.0）

- 商品の登録・編集・アーカイブ、カテゴリ・保管場所の追加
- 在庫数量のワンタップ増減、数量・変更理由の記録
- 商品検索、カテゴリ・在庫不足・期限による絞り込み
- 最低在庫数と目標在庫数から買い物候補を提案
- 買い物リスト、購入完了時の在庫反映
- 期限の登録・注意表示（商品単位、**ロット別ではありません**）
- 在庫の変更履歴（最大200件表示、データは全件保持）
- JSONバックアップ・復元、商品一覧CSV出力
- スマートフォン・PC対応、日本語インターフェース

## 起動

Python 3 がある場合：

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開いてください。パッケージのインストールは不要です。

## GitHub Pages に公開する

1. このリポジトリを GitHub にアップロード（推奨: 新規公開リポジトリ）。
2. GitHub の `Settings > Pages` を開く。
3. `Build and deployment` を `Deploy from a branch` に設定。
4. `main` ブランチの `/ (root)` を選び、`Save`。
5. 数分後、`https://ユーザー名.github.io/リポジトリ名/` で開けます。

## データとプライバシー

- 在庫データはブラウザの `localStorage` にのみ保存され、ネットワークへ送信されません。
- GitHub Pages の HTTPS 環境では、初回読込後にサービスワーカーがアプリ本体をキャッシュします。これにより再訪時のオフライン起動にも対応します（キャッシュやサイトデータの削除時を除く）。
- 端末・ブラウザが異なるとデータは同期されません。
- ブラウザの保存データを削除するとデータも失われます。**設定から定期的にJSONバックアップしてください。**
- 公開リポジトリに個人の在庫データやバックアップファイルをコミットしないでください。
- Webページを共有しても、あなたの在庫データは共有されません。

## テスト

```bash
npm test
```

Node.js 18+ で実行できます。アプリ自体の利用には Node.js は不要です。

## 制限事項と今後の予定

初期版では商品ごとの合計在庫数と単一期限を管理します。複数ロットの期限管理、バーコード読み取り、レシートOCR、複数端末同期、家族共有、購入価格の履歴・金額集計は未実装です。
